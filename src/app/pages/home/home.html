Your Angular app is running

This workspace ships Angular’s agent rules, vendored skills, and MCP servers for the Angular CLI and Neon. Nothing connects to a database until you sign in to Neon.

Connect your agent

  1. Approve the MCP servers

    Your editor asks before it starts angular-cli and Neon from the project config. Approve both.

  2. Sign in to Neon

    When your editor first connects to Neon, it opens your browser to sign in with OAuth. No API key goes into the repository.

  3. Ask for a schema

    Ask your agent to create a notes table in Neon, with row-level security so each person sees only their own notes.

  4. Swap the data source

    Implement NotesRepository with the Neon Data API and return it from the repository factory.
